# Консольная игра "Виселица" (Hangman Game)

Классическая игра **"Виселица"**, реализованная на языке Java в виде консольного приложения. Игрок должен угадать загаданное случайное слово по буквам до того, как закончатся жизни и виселица будет полностью отрисована.

## 🎮 Игровой процесс

1. При запуске программы открывается текстовое меню игры.
2. Игра случайным образом выбирает слово из текстового файла-словаря.
3. На каждом шаге отображается:
   * Замаскированное слово (неотгаданные буквы скрыты под `_`).
   * Количество оставшихся жизней.
   * Список уже введенных букв (автоматически сортируется по алфавиту через запятую).
   * Графическое состояние виселицы в ASCII-арте.
4. Игра завершается победой, если слово разгадано полностью, или поражением, если количество ошибок превысило допустимый лимит.

### Пример интерфейса меню:
```text
┌────────────────────────┐
│      HANGMAN GAME      │
├────────────────────────┤
│  1. Новая игра         │
│  2. Выйти              │
└────────────────────────┘
Выберите действие: 1
```

### Пример интерфейса при победе:
```text
Введите букву: р
Загаданное слово: С В Е Т О К У Л Ь Т У Р А 
Ваши жизни: ❤️❤️❤️
Ранее введенные буквы: А, В, Д, Е, И, К, Л, Н, О, Р, С, Т, У, Ь
    +----+
    |    |
    |    O
    |    |
    |
    |
============

🎉🎉🎉 Вы выиграли! 🎉🎉🎉 Слово: СВЕТОКУЛЬТУРА
```

### Пример интерфейса при поражении:
```text
Введите букву: э
Загаданное слово: _ _ О _ О _ О Д
Ваши жизни:
Ранее введенные буквы: Ё, А, Г, Д, Ж, Л, О, Р, Э
   +---+
   |   |
   |   O
   |  /|\
   |  / \
   |
================

❌❌❌ Вы проиграли! ❌❌❌ Загаданное слово: СКОРОХОД
```
